# 🦜 Pássaros Raros do Mundo

Site educativo sobre pássaros raros e ameaçados de extinção, com imagens, vídeos e sons dessas incríveis aves.

## 📁 Estrutura do Projeto

```
passaros-raros/
├── index.html          # Página principal do site
├── styles.css          # Arquivo de estilos CSS
├── README.md           # Documentação do projeto
├── imagens/            # Pasta para imagens dos pássaros
├── videos/             # Pasta para vídeos
└── audio/              # Pasta para sons dos pássaros
```

## 🎨 Características

- ✅ Design responsivo e moderno
- ✅ Seções sobre espécies raras
- ✅ Galeria de imagens
- ✅ Players de áudio para sons dos pássaros
- ✅ Players de vídeo
- ✅ Informações sobre conservação

## 📝 Como Adicionar Conteúdo

### Imagens
Coloque suas imagens na pasta `imagens/` com os seguintes nomes:
- `arara-azul-lear.jpg`
- `kakapo.jpg`
- `condor-california.jpg`
- `mutum-nordeste.jpg`
- `colhereiro.jpg`
- `galeria-1.jpg` até `galeria-6.jpg`
- `thumb-video-1.jpg` até `thumb-video-3.jpg` (miniaturas dos vídeos)

### Áudios
Coloque os arquivos MP3 na pasta `audio/`:
- `arara-azul.mp3`
- `kakapo.mp3`
- `mutum.mp3`
- `colhereiro.mp3`

### Vídeos
Coloque os arquivos MP4 na pasta `videos/`:
- `arara-azul.mp4`
- `kakapo.mp4`
- `documentario.mp4`

## 🚀 Como Usar no GitHub

### 1. Inicializar o Git
```bash
git init
```

### 2. Adicionar arquivos
```bash
git add .
```

### 3. Fazer o primeiro commit
```bash
git commit -m "Primeiro commit: Site de pássaros raros"
```

### 4. Criar repositório no GitHub
- Acesse [GitHub](https://github.com)
- Clique em "New Repository"
- Dê um nome ao repositório (ex: `passaros-raros`)
- Não inicialize com README (já temos um)
- Clique em "Create Repository"

### 5. Conectar e enviar
```bash
git remote add origin https://github.com/SEU-USUARIO/passaros-raros.git
git branch -M main
git push -u origin main
```

## 🌐 Publicar o Site (GitHub Pages)

1. Vá até o repositório no GitHub
2. Clique em "Settings"
3. No menu lateral, clique em "Pages"
4. Em "Source", selecione "main" branch
5. Clique em "Save"
6. Seu site estará disponível em: `https://SEU-USUARIO.github.io/passaros-raros/`
